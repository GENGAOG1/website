# Sicherheitsnotizen

- Secrets nie in Git committen; in Render Environment bzw. lokalen Umgebungsvariablen speichern.
- Ein starkes, einzigartiges Dashboard-Passwort und nach Möglichkeit MFA für Remote Desktop verwenden.
- Windows-Client mit normalen Benutzerrechten ausführen, sofern nicht anders erforderlich.
- Keine beliebigen Kommandos aus dem Internet an den Client weiterleiten.
- Bei Verdacht auf Kompromittierung Zugangsdaten von einem sauberen Gerät ändern und offizielle Wiederherstellungs-/Sicherheitswerkzeuge verwenden.
